# DET Coach

A beginner-first Duolingo English Test preparation platform built as a **teacher + examiner**.

## Goal
Prepare a learner over a focused 7-day or 14-day sprint. Teacher mode explains English in simple language, demonstrates the skill, checks understanding, and assigns a transfer exercise. Examiner mode removes hints and runs timed DET-style practice.

## Principles
- Teach English first; teach test technique second.
- Diagnose mistakes by skill rather than showing only a score.
- Use original practice material, not leaked/copyrighted test items.
- Match published DET task mechanics where practical.
- Never claim a local practice score is an official DET score.
- Calibrate readiness with the official free DET practice test.
- Close this application during the certified test and follow current official rules.
